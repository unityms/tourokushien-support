# 月次ヒアリング集計ルール

特定技能で支援している方へ毎月ヒアリングを実施し、取引先ごとに Excel／PDF で送付する。
送付前に「中身のチェック → 崩れの修正 → 未返信者への催促」を行う。

## 流れ
1. 取引先ごとの元データ（Excel）を受け取る（月に十数ファイル。何回かに分けて届く）。
2. Google ドライブ「【共有】登録支援者一覧表.xlsx」（file ID: `18MAi06INL9mzH-AMVK1ImwM7CG2-_VNI`）と突き合わせる。
3. チェック結果（未返信・一部未回答・要対応・要確認）を一覧にして報告する。
4. `tools/hearing_fix.py` で修正版を作り、PDF化して画像で崩れを確認してから渡す。
5. 個人情報を含むため、作業ファイル・設定ファイル（氏名入り）はリポジトリに置かない（スクラッチパッドで作業）。

## Eラーニング活用状況（一緒に提出する資料）
- ファイル名：`{年}{月}{社名}様 Eラーニング活用状況.xlsx`（社名は上表の「Eラーニング」列）。
- 中身は基本的に変更しない。旧社名など明らかな誤記だけ、XMLの文字列置換で直す（openpyxlで保存すると図形が消えるため）。

## 質問（LINE／Messenger で各社グループに送信）
```
【しつもん１】 仕事のことでそうだんしたいことはありますか?　作業現場（さぎょうげんば）の環境（かんきょう）や人間関係（にんげんかんけい）など、仕事にかんすることをおしえてください。
(このようなことに、ふまんがあるなど、小さなことでも大丈夫です。)

【しつもん２】 生活のことで相談したいことはありますか?　住んでいる寮のことや、生活トラブルなど困っていることがあればおしえてください。

【しつもん３】 今月の日本語の学習状況を教えてください。 （◯◯を使って勉強している、週に◯時間、1日に◯時間、N◯レベルを勉強中など、くわしくお願いします）

【しつもん４】 12月のJLPT試験に申込みましたか?申し込んだ人はレベルをお知らせください。
```
しつもん４は月ごとに変わる。取引先によって追加質問あり。

## 催促文
```
お疲れ様です
今月の質問にまだリプライがありません
お仕事が終わってからで良いので、必ずリプライしてください
宜しくお願いします
```
一部の質問だけ未回答の方には「今月の質問で、まだ答えていない質問があります（【しつもん○】）」と変えて送る。

## 記入ルール
- 書式：MS Pゴシック 12pt。外枠は太線、内側は細線。最終行は「備考」。
- 1行目のタイトルは `登録支援者定期ヒアリングシート　○月`。質問文中の月（「9月から10月現在まで」等）も対象月に合わせる。
- リプライ日：日付型、表示形式 `m/d`。
  - 回答はあるが日付の記載漏れ → **対象月の末日**。
  - 未返信 → **`期日までの相談報告事項なし`**（2026年10月分から。黒字。それ以前は「リプライありません」赤字太字）。
  - 事情あり → `帰国中（産休・育休中）`、`一時帰国中`、`育休中` 等。
- ベトナム人向け質問（ヤマサORM・ヤマサ醤油）：ベトナム人以外の方の空欄は斜線（右下がり・細線）。国は支援者リストで確認する。
- 赤字：未解決の質問・相談・要望（寮の設備故障、契約・給与・時給の質問、個別相談希望など）。`→石上より…`／`→伝言済み` などの対応メモが付いていて解決済みのものは黒字。
- JLPT 結果欄：受験したが結果未報告 → `（N3結果待ちか？）`。
- 呼名が空欄なら支援者リストから補う。
- 印刷：A4横・幅1ページ・1〜3行目を見出しとして毎ページ印刷。前月から残った手動改ページは消す。長い回答は行の高さを文字量に合わせて広げる。

## 対象者
- 支援者リストの会社名・No.・氏名・呼名・国（V=ベトナム／B=バングラデシュ／N=ネパール／M=ミャンマー）・在籍状況を使う。
- 包括支援・SSW2（期限付きでヒアリングするケースあり）・IS（インターン）・退職者は原則対象外。氏名欄の補足（`（SSW2）ヒアリングは○月まで`）に従う。
- 入国前の方（支援者リスト下段の「済」）は対象外。Eラーニングの表には載ることがある。
- 新しく支援者リストに入った方がヒアリング表にいなければ報告する。

## チェック項目
1. 未返信者（催促リスト）。連続して未返信の月数も添える。
2. 一部の質問だけ未回答の方。
3. リプライ日の漏れ・文字列の日付。
4. 回答の入れ違い（別の質問の回答が入っている）、1セルに複数の回答が詰まっている、同じ文が2回入っている。
5. 前月と同じ文面・他の人と同じ文面の回答（コピーの可能性）。
6. 相談・要望・健康面の気になる記述（赤字＋報告）。
7. 見出しの誤記（「9月から910月」など）。
